# 프로그래머스, 양과 늑대 (실패)

# 문제 소개

[문제 사이트 링크](https://school.programmers.co.kr/learn/courses/30/lessons/92343)

#### 문제 설명

2진 트리 모양 초원의 각 노드에 늑대와 양이 한 마리씩 놓여 있습니다. 이 초원의 루트 노드에서 출발하여 각 노드를 돌아다니며 양을 모으려 합니다. 각 노드를 방문할 때 마다 해당 노드에 있던 양과 늑대가 당신을 따라오게 됩니다. 이때, 늑대는 양을 잡아먹을 기회를 노리고 있으며, 당신이 모은 양의 수보다 늑대의 수가 같거나 더 많아지면 바로 모든 양을 잡아먹어 버립니다. 당신은 중간에 양이 늑대에게 잡아먹히지 않도록 하면서 최대한 많은 수의 양을 모아서 다시 루트 노드로 돌아오려 합니다.

![03_2022_공채문제_양과늑대_01.png](https://asset.programmers.co.kr/files/production/ed7118a9-a99b-4f3a-9779-a94816529e78/03_2022_%E1%84%80%E1%85%A9%E1%86%BC%E1%84%8E%E1%85%A2%E1%84%86%E1%85%AE%E1%86%AB%E1%84%8C%E1%85%A6_%E1%84%8B%E1%85%A3%E1%86%BC%E1%84%80%E1%85%AA%E1%84%82%E1%85%B3%E1%86%A8%E1%84%83%E1%85%A2_01.png)

예를 들어, 위 그림의 경우(루트 노드에는 항상 양이 있습니다) 0번 노드(루트 노드)에서 출발하면 양을 한마리 모을 수 있습니다. 다음으로 1번 노드로 이동하면 당신이 모은 양은 두 마리가 됩니다. 이때, 바로 4번 노드로 이동하면 늑대 한 마리가 당신을 따라오게 됩니다. 아직은 양 2마리, 늑대 1마리로 양이 잡아먹히지 않지만, 이후에 갈 수 있는 아직 방문하지 않은 모든 노드(2, 3, 6, 8번)에는 늑대가 있습니다. 이어서 늑대가 있는 노드로 이동한다면(예를 들어 바로 6번 노드로 이동한다면) 양 2마리, 늑대 2마리가 되어 양이 모두 잡아먹힙니다. 여기서는 0번, 1번 노드를 방문하여 양을 2마리 모은 후, 8번 노드로 이동한 후(양 2마리 늑대 1마리) 이어서 7번, 9번 노드를 방문하면 양 4마리 늑대 1마리가 됩니다. 이제 4번, 6번 노드로 이동하면 양 4마리, 늑대 3마리가 되며, 이제 5번 노드로 이동할 수 있게 됩니다. 따라서 양을 최대 5마리 모을 수 있습니다.

각 노드에 있는 양 또는 늑대에 대한 정보가 담긴 배열 `info`, 2진 트리의 각 노드들의 연결 관계를 담은 2차원 배열 `edges`가 매개변수로 주어질 때, 문제에 제시된 조건에 따라 각 노드를 방문하면서 모을 수 있는 양은 최대 몇 마리인지 return 하도록 solution 함수를 완성해주세요.

---

#### 제한사항

- 2 ≤ `info`의 길이 ≤ 17
    - `info`의 원소는 0 또는 1 입니다.
    - info[i]는 i번 노드에 있는 양 또는 늑대를 나타냅니다.
    - 0은 양, 1은 늑대를 의미합니다.
    - info[0]의 값은 항상 0입니다. 즉, 0번 노드(루트 노드)에는 항상 양이 있습니다.
- `edges`의 세로(행) 길이 = `info`의 길이 - 1
    - `edges`의 가로(열) 길이 = 2
    - `edges`의 각 행은 [부모 노드 번호, 자식 노드 번호] 형태로, 서로 연결된 두 노드를 나타냅니다.
    - 동일한 간선에 대한 정보가 중복해서 주어지지 않습니다.
    - 항상 하나의 이진 트리 형태로 입력이 주어지며, 잘못된 데이터가 주어지는 경우는 없습니다.
    - 0번 노드는 항상 루트 노드입니다.

# 풀이 과정

- 양을 먼저 방문하면 갈 수 있는 노드가 많아진다고 보았다.
- 우선순위 큐로 양을 앞에 두는 BFS Greedy 로 접근했다.
    - 38분 포기. 실행도 포기

```cpp
/*
- 제한사항 숫자 베끼기: 2 ≤ info의 길이 ≤ 17, edges의 세로(행) 길이 = info의 길이 - 1, edges의 가로(열) 길이 = 2
- 내 접근의 연산량 = BFS 순회로 O(N)
- 상태와 전이를 한 문장으로   "상태 = 모든 노드, 전이 = 양과 늑대의 수에 따른 BFS 이동"
- 예시 1개를 손으로 돌리기   (내 로직이 정답을 뱉는지)
*/

int sheep = 1 , wolf = 0;
int answer = 0;
vector<int> info;
int visited [18]= { 0, };
vector<vector<int>> edges ;
priority_queue<pair<int, int>> pq; // first 값 기준 내림차순 정렬, 양을 똑같이 1로, 늑대는 0으로 뒤로 밀려나게

void bfs (){
    
    // 첫 값은 양
    pq.push ({1, 0});
    
    
    while (!pq.empty()){
        pair<int, int> top = pq.top();
        pq.pop();
        
        int animal = top.first, node = top.second;
        visited[node] = 1;
        cout << node << "-> " << sheep << ", " << wolf << '\n';

        if (animal == 1){
            sheep ++;
        }
        else {
            wolf ++;
        }
        
        for (int i = 0; i<edges[node].size(); i++){
                
            int next_node = edges[node][i];
            int next_animal = 1;
            // int next_node = 0, next_animal = 0;
            if (next_animal == 1 && !visited[next_node]){
                pq.push ({next_animal, next_node});
            }
            else if (next_animal == 0 && !visited[next_node]) {
                
                if (sheep > wolf) { // 늑대이긴 하지만 가볼 수 있다면?
                    pq.push ({next_animal, next_node});
                }
                
            }
                
        }
        

    }
}

int solution(vector<int> i, vector<vector<int>> e) {
    
    info = i, edges = e;
    
    cout << i.size() <<", " << e.size() << '\n';
    bfs();
    
    // 루트 노드 출발 -> 해당 노드에 양/늑대가 쫒아옴
    // 중간에 양이 늑대에게 잡아먹히지 않도록 하면서 최대한 많은 수의 양을 모아서 다시 루트 노드로 돌아오려 합니다.
    // 루트 노드에는 항상 양이 있습니다
    // 당신이 모은 양의 수보다 늑대의 수가 같거나 더 많아지면 바로 모든 양을 잡아먹어 버립니다
    
     
    /*
    트리 순회 (대신 양 쪽 먼저 가는) + 모든 경우의 수 탐색은 아님.
    - 늑대를 방문하더라도, 그 후의 양을 획득할 수 있는 트리 순회 조건이 필요함.
    - 우선순위 큐가 필요하다. 큐에 삽입하는 순간 양의 노드가 맨 앞으로 올라와서 BFS가 되게끔.
    - 백트레킹...? // 29분 50초에 떠올림
    */
    
    
    return sheep;
}
```

# 결과 & 근거

- edges 자체를 인접 리스트로 착각했다
    - 원래는 잘 변환했었는데, 착각…
- 우선순위 큐는 순서를 하나로 정하는 도구다. 모든 순서를 시도해야 하는 문제에는 맞지 않다.

```cpp

int n;
vector<int> info;
vector<int> par;        // par[i] = i의 부모 (루트는 -1)
vector<char> seen;      // seen[mask] = 이 방문집합을 이미 탐색했나
int answer;

// mask  : 지금까지 방문한 노드들의 집합 (i번 비트가 1이면 i번 노드 방문)
// sheep : 모은 양의 수,  wolf : 따라온 늑대의 수
void dfs(int mask, int sheep, int wolf) {

    // ★ 같은 방문집합이면 양/늑대 수가 동일하고 이후 탐색도 동일하다.
    //   서로 다른 "방문 순서"가 같은 "방문 집합"에 도달하므로 중복이 발생한다.
    //   이 한 줄이 17!(팩토리얼)을 2^17(131,072)로 눌러준다. 실측 47만배 차이.
    if (seen[mask]) return;
    seen[mask] = 1;

    answer = max(answer, sheep);

    for (int nx = 0; nx < n; nx++) {
        if (mask & (1 << nx)) continue;            // 이미 방문한 노드
        if (par[nx] < 0) continue;                 // 루트는 시작부터 방문 상태
        if (!(mask & (1 << par[nx]))) continue;    // 부모가 미방문 → 아직 접근 불가
        //  ↑ 트리에서는 방문한 노드를 거쳐 자유롭게 되돌아갈 수 있으므로,
        //    "현재 위치"는 중요하지 않다. "부모가 열렸는가"만 보면 된다.

        int ns = sheep + (info[nx] == 0);          // info 0 = 양
        int nw = wolf  + (info[nx] == 1);          // info 1 = 늑대

        if (ns <= nw) continue;                    // 늑대 수가 양 이상 → 다 잡아먹힌다
        //  ↑ 이 가지를 버리는 것이지, 여기서 멈추는 게 아니다.
        //    다른 노드를 고르는 선택은 계속 시도된다 = 백트래킹

        dfs(mask | (1 << nx), ns, nw);
        // mask 는 값으로 넘기므로 자동 복구된다. visited 배열을 되돌릴 필요가 없다.
    }
}

int solution(vector<int> I, vector<vector<int>> edges) {
    info = I;
    n = info.size();

    // ★ edges 는 "간선 목록"이다. edges[i] = [부모, 자식] 이고
    //   edges[node] 는 node의 자식 목록이 아니다. 반드시 변환해야 한다.
    vector<vector<int>> adj(n);
    for (auto& e : edges) {
        adj[e[0]].push_back(e[1]);
        adj[e[1]].push_back(e[0]);   // 양방향으로 담아두고 BFS로 부모를 확정한다
    }

    // 루트(0번)에서 BFS로 각 노드의 부모를 구한다.
    // edges 의 방향이 보장되더라도 이렇게 하면 입력 형식에 의존하지 않아 안전하다.
    par.assign(n, -1);
    vector<int> vis(n, 0);
    queue<int> q;
    q.push(0); vis[0] = 1;
    while (!q.empty()) {
        int cur = q.front(); q.pop();
        for (int nx : adj[cur]) {
            if (vis[nx]) continue;
            vis[nx] = 1;
            par[nx] = cur;
            q.push(nx);
        }
    }

    seen.assign(1 << n, 0);
    answer = 1;
    dfs(1, 1, 0);      // 루트 방문 상태(비트 0만 켜짐), 양 1마리, 늑대 0
    return answer;
}
```

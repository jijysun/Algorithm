# 문제 소개

[문제 사이트 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12914)

효진이는 멀리 뛰기를 연습하고 있습니다. 효진이는 한번에 1칸, 또는 2칸을 뛸 수 있습니다. 칸이 총 4개 있을 때, 효진이는

(1칸, 1칸, 1칸, 1칸)
(1칸, 2칸, 1칸)
(1칸, 1칸, 2칸)
(2칸, 1칸, 1칸)
(2칸, 2칸)

의 5가지 방법으로 맨 끝 칸에 도달할 수 있습니다. 멀리뛰기에 사용될 칸의 수 n이 주어질 때, 효진이가 끝에 도달하는 방법이 몇 가지인지 알아내, 여기에 1234567를 나눈 나머지를 리턴하는 함수, solution을 완성하세요. 예를 들어 4가 입력된다면, 5를 return하면 됩니다.

#### 제한 사항

- n은 1 이상, 2000 이하인 정수입니다.

#### 입출력 예

| n | result |
| --- | --- |
| 4 | 5 |
| 3 | 3 |

#### 입출력 예 설명

입출력 예 #1

위에서 설명한 내용과 같습니다.

입출력 예 #2
(2칸, 1칸)
(1칸, 2칸)
(1칸, 1칸, 1칸)

총 3가지 방법으로 멀리 뛸 수 있습니다.

# 풀이 과정

- n=6까지 손으로 나열해서 1, 2, 3, 5, 8, 13 을 얻었다.
    - dp[i] = dp[i-1] + dp[i-2] (피보나치) 가 보였다.
- 마지막 한 걸음이 1칸이면 직전은 i-1칸, 2칸이면 직전은 i-2칸 상태다.
    - 두 경우가 겹치지 않으니 합이 된다. 경우의 수라 min/max 가 아니라 덧셈이다.

```cpp
/*
- 제한사항 숫자 베끼기: n은 1 이상, 2000 이하인 정수입니다.
- 내 접근의 연산량 = 1은 이미 주어짐 -> 2~n 까지의 순회라 O(N) 정도.
- 상태와 전이를 한 문장으로: [상태: 현 칸 수] [전이: 이전 칸 끼리 더하기]
- 예시 1개를 손으로 돌리기: n이 91 까지는 버티는데, 그 이후부터 오버플로 발생 및 실패.

① 무엇을 묻나: 효진이가 끝에 도달하는 방법 = 경우의 수
② 중복 부분 문제: 계속, 이번 칸에서 몇 칸을 뛸 지를 물어봄. = 동일 중복 문제가 발생
③ 최적 부분 구조: 지금 점화식이 발생하며, 이전 값을 활용해 현재의 최적의 값을 나타냄!
④ 비교 함수: 1/2칸 매번 비교하기는 힘들어. 경우의 수 이기도 하고, 만약 최소값이라면 얘기가 달라졌겠지.
⑤ 쪼갤 수 있나: 더 쪼개지지는 않음
 *
 */

// long long dp [2002];
int dp [2002];
long long solution(int n) {
    long long answer = 0;

    // 5 까지만 예시를 들어보자, 문제 예시 기준 뛰는 순서는 상관 X
    dp[1] = 1l; // 1
    dp[2] = 2l; // 11, 2
    /*dp[3] = 3; // 111, 12, 21 3
    dp[4] = 5; // 1111, 112, 121, 211, 22
    dp[5] = 8; // 11111, 1112, 1121, 1211, 2111, 122, 212, 221
    dp[6] = 13; // 111111, 11112, 11121, 11211, 12111, 21111, 1122, 1212, 2112, 2121, 2211, 1221, 222
    dp[7] = ;//
    */
    // dp[i] = i칸 까지 뛸 수 있는 경우의 수 = dp[i-1] + dp[i-2]? 6까지 세워보니 점화식이 발생.
    for (int i = 3; i <= n; i++)
    {
        // 모듈러 분배 법칙에 의해, "끝까지 키운 뒤 한 번 나눈 값"과 "매 단계 나눠가며 얻은 값"이 수학적으로 동일!
        // `나머지를 리턴`이라는 말이 나오면 신호!
        dp[i] = (dp[i-1] + dp[i-2])%1234567;
        cout << "dp[" <<i << "]: " << dp[i] << '\n';
    }
    // dp[90]: 4660046610375530309
    // dp[91]: 7540113804746346429 -> 이후부터 오버플로의 연속.

    // 효진이가 끝에 도달하는 방법이 몇 가지인지 알아내, 여기에 1234567를 나눈 나머지를 리턴
    return dp[n];
}

int main () {
    // 2000을 넣으니, -1117119 언더플로 발생.
    cout << solution(2000) << endl;
    return 0;
}
```

# 결과 & 근거

- 부분 성공 (16분, 설계는 정답 / 오버플로로 오답)
- 점화식은 맞았는데 오버플로로 틀렸다.
    - long long 으로도 n=92 에서 터진다.
    - dp[91] = 7,540,113,804,746,346,429 까지는 long long 한계(약 9.22×10^18) 안이지만, dp[92] 가 1.22×10^19 로 넘어가 음수가 된다.
- 원인은 모듈러를 마지막에 한 번만 취한 것이다.
    - 나머지 연산은 덧셈·곱셈에 분배된다.
- 모듈러 분배 법칙이 적용되므로, 매 결과에 적용 시켜주어도, 결과는 일치한다.
    - 즉, 문제/지문에 “~로 사칙연산한 나머지를 리턴하세요!” 라는 글이 있으면  "중간 값이 자료형을 넘는다"는 출제자의 경고라고 할 수 있다.

#### 모듈러 산술 정리

| 연산 | 처리 | 주의 |
| --- | --- | --- |
| 덧셈 | (a + b) % m  |  매 연산마다 |
| 곱셈 |  (a * b) % m | a,b < m ≤ 10^9 이면 곱이 10^18 → long long 필수 |
| 뺄셈 | (a - b + m) % m | +m 없으면 음수 (C++ % 는 피제수 부호를 따른다) |
| 나눗셈 | 모듈러 역원 필요 | m 이 소수일 때만 페르마 소정리로 가능 |

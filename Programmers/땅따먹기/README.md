# 프로그래머스, 땅따먹기 (실패)

# 문제 소개

[문제 사이트 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12913)

#### **문제 설명**

땅따먹기 게임을 하려고 합니다. 땅따먹기 게임의 땅(land)은 총 N행 4열로 이루어져 있고, 모든 칸에는 점수가 쓰여 있습니다. 1행부터 땅을 밟으며 한 행씩 내려올 때, 각 행의 4칸 중 한 칸만 밟으면서 내려와야 합니다. **단, 땅따먹기 게임에는 한 행씩 내려올 때, 같은 열을 연속해서 밟을 수 없는 특수 규칙이 있습니다.**

예를 들면,

| 1 | 2 | 3 | 5 |

| 5 | 6 | 7 | 8 |

| 4 | 3 | 2 | 1 |

로 땅이 주어졌다면, 1행에서 네번째 칸 (5)를 밟았으면, 2행의 네번째 칸 (8)은 밟을 수 없습니다.

마지막 행까지 모두 내려왔을 때, 얻을 수 있는 점수의 최대값을 return하는 solution 함수를 완성해 주세요. 위 예의 경우, 1행의 네번째 칸 (5), 2행의 세번째 칸 (7), 3행의 첫번째 칸 (4) 땅을 밟아 16점이 최고점이 되므로 16을 return 하면 됩니다.

#### 제한사항

- 행의 개수 N : 100,000 이하의 자연수
- 열의 개수는 4개이고, 땅(land)은 2차원 배열로 주어집니다.
- 점수 : 100 이하의 자연수

#### 입출력 예

| land | answer |
| --- | --- |
| [[1,2,3,5],[5,6,7,8],[4,3,2,1]] | 16 |

#### 입출력 예 설명

입출력 예 #1

문제의 예시와 같습니다.

# 풀이 과정

- 어느 정도 점화식을 세운 거 같긴 했다.
    - `dp[i][j] = dp[i-1]` 에서의 최대값 + `land[i][j]` 로 잡고, "직전에 밟은 열"을
    pre_col 변수 하나로 추적했다.
    - 같은 열이면 그 열 제외 최댓값을 다시 찾는 식으로 짰다.
- 하지만 이전 열과 같은 열에 위치할 경우 어떻게 처리해야 할 지 고민하다가 TimeOut 으로 포기했다.
    - 25분 실패. 공식 예시에서 17이 나왔다 (정답 16).

```cpp
/*
- 제한사항 숫자 베끼기: 행의 개수 N : 100,000 이하의 자연수, 열의 개수는 4개, 배열 land는 2차원, 점수 : 100 이하 자연수
- 내 접근의 연산량 =
- 상태와 전이를 한 문장으로:
- 예시 1개를 손으로 돌리기

① 무엇을 묻나: 마지막 행까지 모두 내려왔을 때, 얻을 수 있는 점수의 '최대값'
② 중복 부분 문제: 지금 내가 밟기가 가능한, 최고 점수를 밟는 것을 묻는다.
③ 최적 부분 구조: 점화식이 발생 -> 이전 값을 현 최적값을 구할 때 사용!
④ 비교 함수: 비교 함수가 있긴 하나, 이전과 같은 열 제외 max(가능한 칸들) 정도이다.
⑤ 쪼갤 수 있나: 쪼갤수도 없음
 */

int dp[100001][4]; // dp[i][j] = 이전 밟은 땅 + 지금 밟을 수 있는 최대 값.
// int one_dp[100001]; // 굳이 2차원으로 표현해야 하나? 그래도 2차원으로 풀어볼까

int solution(vector<vector<int> > land)
{
    int answer = 0, pre_col = 0, col=0; // 이전 열 인덱스

    // 처음만 초기화
    for (int i = 0; i<land[0].size(); i++)
    {
        dp[0][i] = land[0][i];
        if (answer < dp[0][i]) {
            // 첫 값 초기화, 제일 큰거 고르기,
            answer = dp[0][i], pre_col = i;
        }
        cout << dp[0][i] << " ";
    }
    cout << ", pre_col: " << pre_col << endl << "------\n";

    // N행 4열, 칸마다 점수.
    // 대신 한 열 쭈우욱이 아님. 같은 열을 계속해서 밟을 수 없어.
    for (int i = 1; i<land.size(); i++){

        int cur_max = 0;
        for (int j = 0; j<land[i-1].size(); j++) {
            // 이전 열과 같은 값 제외 최대값을 고르는 것.
            for (int k = 0; k<land[i-1].size(); k++)
            {
                if (k == pre_col) {
                    // 이전 행에서 그거 제외 max를 찾아야 해.
                    int last_max = 0;
                    for (int l = 0; l<land[i-1].size(); l++)
                    {
                        if (l == pre_col)
                        {
                            continue;
                        }
                        last_max = max(last_max, land[i-1][l]);
                    }
                    cur_max = cur_max > last_max + land[i][j] ? cur_max : dp[i-1][pre_col] + land[i][j];
                }
                cur_max = cur_max > dp[i-1][pre_col] + land[i][j] ? cur_max :dp[i-1][pre_col] + land[i][j];
            }
            dp[i][j] = cur_max;
        }

        // 제일 큰 값 찾기.

        for (int j = 1; j<land[i].size(); j++) {
            if (dp[i][j-1] < dp[i][j])
            {
                pre_col = j;
            }
            else
            {
                pre_col = j-1;
            }
        }
    }

    for (int i = 0; i<land.size(); i++)
    {
        for (int j = 0; j<4; j++)
        {
            cout << dp[i][j] << " ";
        }
        cout << endl;
    }

    return dp[land.size()-1][pre_col];
}
```

# 결과 & 근거

- 핵심 점화식:  `dp[i][j]` = i행에서 j열을 밟았을 때까지의 최대 누적 점수
    - 전이 = `dp[i][j] = land[i][j] + max(dp[i-1][k]), k != j`
- 2차원 배열을 선언했지만 1차원처럼 썼다.
    - pre_col 을 하나로 정하는 순간 "직전 행에서 어느 열을 밟았나"의 가능성이 1개로 붕괴된다.
- 사실 각 칸 마다 for 문을 다시 돌려서 최적 값을 찾으면 그만이였다.
    - 직감은 맞았는데, 이걸 2차원 적으로 풀려고 하다보니 막혔던 것 같다.

```cpp
// dp[i][j] = i행에서 "j열을 밟았을 때" 그 시점까지의 최대 누적 점수
//            ★ j 가 곧 "직전 선택"이다. 그래서 pre_col 같은 변수가 필요 없다.
int dp[100001][4];

int solution(vector<vector<int> > land)
{
    int n = land.size();

    // 0행: 어느 열을 밟든, 그 시점 점수는 그 칸 점수 그대로다.
    //      "최댓값 하나만 고르지 않는다" — 4가지 가능성을 전부 살려둔다.
    for (int j = 0; j < 4; j++) {
        dp[0][j] = land[0][j];
    }

    for (int i = 1; i < n; i++) {
        for (int j = 0; j < 4; j++) {          // "이번 행에서 j열을 밟는다"고 가정하고 계산
            int best_prev = 0;

            for (int k = 0; k < 4; k++) {      // 직전 행에서 올 수 있는 열을 전부 본다
                if (k == j) continue;          // 같은 열은 금지 ← 제약이 여기 한 줄로 끝난다
                best_prev = max(best_prev, dp[i-1][k]);
                // "j를 제외한 직전 행 최댓값"을 구한다.
                // 이 값이 j마다 달라지기 때문에, 직전 행의 4개 값을 모두 들고 있어야 한다.
                // pre_col 하나로 좁히면 바로 이 지점에서 틀린다.
            }

            dp[i][j] = best_prev + land[i][j];
        }
    }

    // 마지막 행에서 어느 열로 끝났는지는 자유 → 4개 중 최댓값
    return max({ dp[n-1][0], dp[n-1][1], dp[n-1][2], dp[n-1][3] });
}
```

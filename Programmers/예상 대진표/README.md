# 프로그래머스, 예상 대진표 (실패)

# 문제 소개

[문제 사이트 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12985)

△△ 게임대회가 개최되었습니다. 이 대회는 N명이 참가하고, 토너먼트 형식으로 진행됩니다. N명의 참가자는 각각 1부터 N번을 차례대로 배정받습니다. 그리고, 1번↔2번, 3번↔4번, ... , N-1번↔N번의 참가자끼리 게임을 진행합니다. 각 게임에서 이긴 사람은 다음 라운드에 진출할 수 있습니다. 이때, 다음 라운드에 진출할 참가자의 번호는 다시 1번부터 N/2번을 차례대로 배정받습니다. 만약 1번↔2번 끼리 겨루는 게임에서 2번이 승리했다면 다음 라운드에서 1번을 부여받고, 3번↔4번에서 겨루는 게임에서 3번이 승리했다면 다음 라운드에서 2번을 부여받게 됩니다. 게임은 최종 한 명이 남을 때까지 진행됩니다.

이때, 처음 라운드에서 A번을 가진 참가자는 경쟁자로 생각하는 B번 참가자와 몇 번째 라운드에서 만나는지 궁금해졌습니다. 게임 참가자 수 N, 참가자 번호 A, 경쟁자 번호 B가 함수 solution의 매개변수로 주어질 때, 처음 라운드에서 A번을 가진 참가자는 경쟁자로 생각하는 B번 참가자와 몇 번째 라운드에서 만나는지 return 하는 solution 함수를 완성해 주세요. **단, A번 참가자와 B번 참가자는 서로 붙게 되기 전까지 항상 이긴다고 가정합니다.**

#### 제한사항

- N : 21 이상 220 이하인 자연수 (2의 지수 승으로 주어지므로 부전승은 발생하지 않습니다.)
- A, B : N 이하인 자연수 (단, A ≠ B 입니다.)

---

#### 입출력 예

| N | A | B | answer |
| --- | --- | --- | --- |
| 8 | 4 | 7 | 3 |

#### 입출력 예 설명

입출력 예 #1

첫 번째 라운드에서 4번 참가자는 3번 참가자와 붙게 되고, 7번 참가자는 8번 참가자와 붙게 됩니다. 항상 이긴다고 가정했으므로 4번 참가자는 다음 라운드에서 2번이 되고, 7번 참가자는 4번이 됩니다. 두 번째 라운드에서 2번은 1번과 붙게 되고, 4번은 3번과 붙게 됩니다. 항상 이긴다고 가정했으므로 2번은 다음 라운드에서 1번이 되고, 4번은 2번이 됩니다. 세 번째 라운드에서 1번과 2번으로 두 참가자가 붙게 되므로 3을 return 하면 됩니다.

# 풀이 과정

- 참가자 2^20명을 배열로 만들어 라운드를 시뮬레이션하면 메모리/시간 모두 낭비.
    - 필요한 건 a, b 두 명의 번호 변화뿐이다.
- 1라운드에서 (1,2)가 붙고 이긴 쪽이 2라운드 1번, (3,4)가 붙고 이긴 쪽이 2번.
일반화하면 **번호 k -> (k+1)/2**.
- "둘이 만났다"를 `b - a == 1 && a가 홀수` 로 판정하려 했는데, 이러면
a < b 를 보장해야 해서 스왑이 필요해진다.
- 대신 **번호를 접었을 때 a == b 가 되는 순간**을 보면, 그게 곧 맞붙는 라운드다.
    - 대소 관계가 무의미해지므로 스왑 자체가 사라진다.

```cpp
int solution(int n, int a, int b)
{
    int answer = 1;

    /*
    전체 참가자 수는 2^20 = 그냥 순회하면 무조건 TLE
    - 어쨌든 그냥 순회가 아닌 지수 별로 순회?
    - 그러면 20강 만큼 생기는 거니까. + 부전승 발생 X
    - 2^20승이면 Int 범위인가? 
    
    ex 1.
    12 34(A) 56 7(B)8 1라운드
    -> 1, 2(A), 3, 4(B) 2라운드
    -> 1 (A), 2(B) 3라운드
    
    ex2. 
    12 34(A) 5(B)6 78 1라운드
    -> 1, 2(A), 3(B), 4 2라운드
    -> 1 (A), 2(B) 3라운드
    
    ex3. 
    12 3(A)4 5(B)6 78 1라운드
    -> 1, 2(A), 3(B), 4 2라운드
    -> 1 (A), 2(B) 3라운드
    
    로직
    - 무조건 나누기 2 (나머지가 생기는 경우 +1)
    - A와 B가 붙어있더라도, 경기를 치루지 않을 경우가 있다 -> ex2.
    - 처음 A와 B의 차이? 
    - 예시 1 기준 3차이가 났었음.
    
    A와 B가 홀 짝이면서 1차이 나는 경우 겨룬 것
    만약 짝 홀, 짝짝, 홀홀 이면, 아직 만나지 않은 것
    
    */
    
    if (a > b){
        int temp = a;
        a = b, b = a; // 레전드 실수
    }
    // cout << a << " " << b << '\n';
    
    while (true){
        if (a%2 == 1 && b%2 == 0 && b-a == 1){ // 단순 비교가 오래 걸리는 것인가
            // cout << "만났습니다, "<< a << " " << b << '\n';
            break;
        }
        
        answer++;
        
        
        if (a%2 == 1){
            a = a/2+1;
        }
        else {
            a/=2;
        }
        
        if (b%2 == 1){
            b = b/2+1;
        }
        else {
            b/=2;
        }
        
        // a = a%2 == 1 ? a/2+1 : a/2;
        // b = b%2 == 1 ? b/2+1 : b/2; // 이것도 오래 걸리나?
        
        // cout << a << " " << b << '\n';
    }
    
    // 17:30초, 44.1 / 100.0 - 대부분이 TLE
    // 23분 삼항연산자가 느릴것으로 우려 ->  44.1 / 100.0 

    return answer;
}
```

# 결과 & 근거

- 디버깅도 제대로 못했다.
    - 로직에서 TLE 발생으로, 더욱 효율적인 비교를 해야 한다고 생각했다.
    - 사실 a, b 대소 변환에서 temp를 안쓰는 실수를 하였다.
- 대소 변환도 사실 필요가 없다.
    - 둘이 만났을 때 에는 번호 전환 시 1로 같은 번호가 된다

```cpp
#include <iostream>
using namespace std;

/*
1. 제한 : n = 2^1 ~ 2^20 (= 1,048,576, int 범위 안전). a, b <= n
2. 연산량 = (라운드 수 log2(n) = 최대 20) x (전이 O(1)) = 20회. 통과 O
3. 상태와 전이 : 각 참가자의 "다음 라운드 번호" = (현재 번호 + 1) / 2
4. 예제 손검증 : O
*/

int solution(int n, int a, int b)
{
    int answer = 0;

    /* 핵심 관찰
       1라운드에서 (1,2)가 붙고 (3,4)가 붙는다. 이긴 쪽은 2라운드에서 각각 1번, 2번이 된다.
       즉 번호 k 의 다음 라운드 번호는 (k+1)/2 다.
         k=1 -> 1,  k=2 -> 1   (둘이 만났으므로 같은 번호가 된다)
         k=3 -> 2,  k=4 -> 2
       => "만났다"를 b-a==1 같은 조건으로 따로 판정할 필요가 없다.
          번호를 한 번 접었을 때 a 와 b 가 같아지면, 그 라운드에서 만난 것이다.
          같아지는 순간을 보므로 a 와 b 의 대소 관계도 상관없다 -> swap 불필요.  */

    while (a != b) {        // ★ a == b 가 탈출 조건이므로 무한 루프가 구조적으로 불가능하다
        a = (a + 1) / 2;    //   (a-b)의 절댓값이 매 라운드 최소 절반으로 줄어 반드시 종료
        b = (b + 1) / 2;
        answer++;           // 한 번 접을 때마다 라운드 1 증가
    }

    return answer;          // a 와 b 가 같아진 라운드 = 둘이 맞붙는 라운드
}
```

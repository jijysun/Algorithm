#### **문제 설명**

가로 길이가 2이고 세로의 길이가 1인 직사각형모양의 타일이 있습니다. 이 직사각형 타일을 이용하여 세로의 길이가 2이고 가로의 길이가 n인 바닥을 가득 채우려고 합니다. 타일을 채울 때는 다음과 같이 2가지 방법이 있습니다.

- 타일을 가로로 배치 하는 경우
- 타일을 세로로 배치 하는 경우

예를들어서 n이 7인 직사각형은 다음과 같이 채울 수 있습니다.

![Imgur](https://i.imgur.com/29ANX0f.png)

직사각형의 가로의 길이 n이 매개변수로 주어질 때, 이 직사각형을 채우는 방법의 수를 return 하는 solution 함수를 완성해주세요.

#### 제한사항

- 가로의 길이 n은 60,000이하의 자연수 입니다.
- 경우의 수가 많아 질 수 있으므로, 경우의 수를 1,000,000,007으로 나눈 나머지를 return해주세요.

# 풀이 과정

- 바로 이전에 풀었던 문제와 점화식이 매우 똑같아서 빠르게 풀었다.

```cpp
#include <string>

using namespace std;
/*
- 제한사항 숫자 베끼기: 가로의 길이 n은 60,000이하의 자연수 + 경우의 수를 1,000,000,007으로 나눈 나머지를 return
- 내 접근의 연산량 = N * 더하기 연산 -> O(N) 이 최대
- 상태와 전이를 한 문장으로: [상태: 현재 값, dp[i].] [전이: 이전 값을 활용해서 덧셈]
- 예시 1개를 손으로 돌리기 -> dp[5] 까지 완료

① 무엇을 묻나: 경우의 수
② 중복 부분 문제: n 값이 상관 없이, 가로/세로 배치했을 때의 경우의 수를 묻는다.
③ 최적 부분 구조: 점화식이 발생 -> 이전 값을 현 최적값을 구할 때 사용!
④ 비교 함수: 비교라는 활동 자체가 발생하지 않음.
⑤ 쪼갤 수 있나: 쪼갤수도 없음
 */

int dp[60001];

int solution(int n) {
    int answer = 0;

    dp[1] = 1; // 세로1
    dp[2] = 2; // 세로11, 가로11
    // dp[3] = 3; // 세로111, 가2세1, 세1가2
    // dp[4] = 5; // 세4, 세세가가, 세가가세, 가가세세, 가가가가,
    // dp[5] = 8; // 세5, 세세세가가, 세세가가세, 세가가세세, 가가세세세, 가가가가세, 가가세가가, 세가가가가
    // dp[i] = dp[i-1] + dp[i-2]라는 규칙 발생

    for (int i = 3; i<=n; i++)
    {
        dp[i] = (dp[i-1] + dp[i-2])%1000000007;
    }

    // 가로세로: 2/1 인 직사각형 활용 -> 가로세로 n*2인 바닥 채우기
    // 경우의 수: 타일을 가로 or 세로로 배치.

    return dp[n];
}
```

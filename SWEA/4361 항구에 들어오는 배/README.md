# 문제 소개

[문제 사이트 하이퍼링크](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWMedCxalW8DFAXd&categoryId=AWMedCxalW8DFAXd&categoryType=CODE&problemTitle=4371&orderBy=FIRST_REG_DATETIME&selectCodeLang=ALL&select-1=&pageSize=10&pageIndex=1)

민석이는 항구가 있는 작은 마을에 산다.

이 항구에는 배가 아주 드물게 지나다닌다.

민석이는 어느날 모든 배들이 항구에 들어온 것을 보았다.

민석이는 이 날을 1일차로 지정하였다.

민석이는 배가 한 척이라도 항구에 들렀던 날을 “즐거운 날"로 이름짓고, 1일차부터 즐거운 날들을 모두 기록하였다.

그러던 중, 한 가지 규칙을 발견했는데, 그 규칙은 각 배들은 항구에 주기적으로 들른다는 것이었다.

예를 들어, 주기가 3인 배는 항구에 1일차, 4일차, 7일차, 10일차 등에 방문하게 된다.

민석이가 1일차부터 기록한 “즐거운 날"들의 목록이 주어질 때, 항구에 들렀던 배의 최소 수를 알아내자.

이 때, 항상 답이 존재하는 입력만 주어진다.

**[입력]**

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.

각 테스트 케이스의 첫 번째 줄에 즐거운 날의 수 N이 주어진다. (2 ≤ N ≤ 5000)

각 테스트 케이스의 두 번째 줄부터 N개의 줄에 걸쳐 즐거운 날의 정보가 오름차순으로 정렬되어 주어진다.

시작하는 날은 항상 1일이고, 마지막 날은 109보다 작은 값이다.

**[출력]**각 테스트 케이스마다 항구에 들렀던 배의 최소 수를 출력한다.

# 풀이 과정

- 1일차는 모든 배가 들어온 날이라 빼고, 다음 즐거운 날까지의 차이를 배의 주기로 봤다.
- (날짜 − 1)이 이미 있는 주기 중 하나로 나누어 떨어지면 기존 배가 들어온 것이고, 아니면 새 배의 주기로 추가했다.
- 19분에 구현했는데 두 번째 예제에서 4가 나와서, 모든 주기를 다 확인한 뒤 판단하도록 조건문을 뒤집어 22분에 해결했다.

```cpp
#include<iostream>
#include <map>
#include <vector>

using namespace std;
/*
 * 작은 마을, 배가 드물게 지나가다가 어셈블 하는 날을 봄 = 1일차로 지정
 * - 배가 한 척이라도 항구에 들렀던 날을 “즐거운 날"로 명명.
 * - 1일차부터 즐거운 날들을 모두 기록. 배들은 모두 주기적인 규칙을 갖고 들른다는 것.
 * - 주기가 3인 배는 항구에 1일차, 4일차, 7일차, 10일차 등에 방문하게 된다.
 * -  1일차부터 기록한 “즐거운 날"들의 목록이 주어질 때, 항구에 들렀던 배의 최소 수
 * 이 때, 항상 답이 존재하는 입력만 주어진다.
 *
 * 예시 기준
 * 1, 3, 4가 즐거운 날. 이떄 들었던 배의 최소 수는 2
 * - 1, 3, 4 에는 적어도 두 척의 배가 있었다.
 * - 1은 1일차이므로 제외
 * - 1 -> 3 주기를 갖는 배 하나 + 1 -> 4 주기를 갖는 배 하나가 있어서 최소 배 수는 2가 되는 것!
 *
 * 1, 7, 10, 13, 19가 즐거운 날이었다.
 * - 1 -> 7인 주기 하나 -> 다음은 13
 * - 1 -> 10 인 주기 하나 -> 다음은 19.
 * - 즉 배는 총 두 척
 *
 * 그럼 1, 3, 5 처럼 같은 날 5에 두 척이 방문하며, 주기가 서로 같은 배수라면?
 * - 어쨌든 배의 최소 수를 출력해야 하니, 1척이 된다. 예시 맨 마지막과 같은 원리.
 *
 * 만약 벡터가 비었거나, 백터에 있는 값에 대해 나누어 떨어지지 않는다면 즉 벡터에 입력값 -1 을 넣는다.
 * 만약 (입력값-1)%벡터 값에 대해 0이라면, 이전 배로 칠 수 있음. 벡터에 넣지 않는다.
 * 정답 = vector.size();
 */

int main(int argc, char** argv)
{
	int test_case;
	int T;
	cin>>T;

	vector<int> v;
	for(test_case = 1; test_case <= T; ++test_case) {
		int b;
		cin >> b;

		v.clear();

		for (int i = 0; i<b; i++) {
			int boat;
			cin >> boat;

			if (boat == 1) continue;

			if (v.empty()) {
				v.push_back(boat-1); // 1일차 부터 시작해서
			}
			else {
				bool insert = false;
				for (int j = 0; j<v.size(); j++) {
					if ( (boat -1) % v[j] ==  0) { // 하나라도 딱 떨어지면, 같은 배 취급 가능
						insert = true;
					}
				}
				if (!insert) {
					v.push_back(boat-1);
				}
			}
		}
		cout << "#" << test_case << " " << v.size() << endl;

		/*
		 *
		 * 19분 구현 완료. 두 번째 예시에 대해 4를 뱉어버림.
		 * - 조건문을 뒤집자. 보트 벡터 내 모든 값에 대해 나머지 값을 판별해야 한다.
		 *
		 * 22분 해결 완료.
		 */

	}
	return 0;//정상종료시 반드시 0을 리턴해야합니다.
}
```

# 결과 & 근거

**성공 (22분)**

- 날짜가 오름차순이라, 기존 배로 설명되지 않는 가장 이른 날은 새 배의 첫 방문일 수밖에 없다. 그래서 그 날 − 1을 주기로 추가하는 그리디가 최소다.
- 기존 주기 중 하나라도 나누어떨어지면 바로 멈추면 된다.

```cpp
#include<iostream>
#include <vector>

using namespace std;

int main(int argc, char** argv)
{
	int test_case;
	int T;
	cin >> T;

	vector<int> v;   // 지금까지 필요한 배들의 주기
	for (test_case = 1; test_case <= T; ++test_case) {
		int b;
		cin >> b;
		v.clear();   // 전역(바깥) 벡터라 테스트 케이스마다 초기화

		for (int i = 0; i < b; i++) {
			int boat;
			cin >> boat;
			if (boat == 1) continue;   // 1일차는 모든 배가 들어온 날

			// 이미 있는 배(주기 p) 중에 이 날 들어오는 배가 있나?
			// 주기 p인 배는 1, 1+p, 1+2p ... 에 들어오므로 (boat - 1) % p == 0
			bool found = false;
			for (int j = 0; j < v.size(); j++) {
				if ((boat - 1) % v[j] == 0) { found = true; break; }
			}

			// 아무 배도 설명 못 하는 가장 이른 날 → 이 날이 첫 방문인 새 배 (주기 = boat - 1)
			if (!found) v.push_back(boat - 1);
		}
		cout << "#" << test_case << " " << v.size() << '\n';
	}
	return 0;//정상종료시 반드시 0을 리턴해야합니다.
}

```

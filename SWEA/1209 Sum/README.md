다음 100X100의 2차원 배열이 주어질 때, 각 행의 합, 각 열의 합, 각 대각선의 합 중 최댓값을 구하는 프로그램을 작성하여라.다음과 같은 5X5 배열에서 최댓값은 29이다.

![캡처.PNG](%EC%BA%A1%EC%B2%98.png)

**[제약 사항]**

총 10개의 테스트 케이스가 주어진다.

배열의 크기는 100X100으로 동일하다.

각 행의 합은 integer 범위를 넘어가지 않는다.

동일한 최댓값이 있을 경우, 하나의 값만 출력한다.

**[입력]**

각 테스트 케이스의 첫 줄에는 테스트 케이스 번호가 주어지고 그 다음 줄부터는 2차원 배열의 각 행 값이 주어진다.

**[출력]**

#부호와 함께 테스트 케이스의 번호를 출력하고, 공백 문자 후 테스트 케이스의 답을 출력한다.

# 풀이 과정

- 행 합 / 열 합 / 두 대각선 합을 구해 최댓값을 출력. 로직 자체는 자명하다.
- 그런데 10개 중 1개만 통과했고, 같은 예제를 두 번 넣으면 1712 / 1741 로 값이 달라졌다.
    - "어디 초기화가 안 된다"고 의심해 배열을 벡터로 바꾸는 데까지 시간을 썼다.
    - 사실 초기화는 처음부터 완벽했다 (max_sum = 0, arr.assign).

```cpp
vector<vector<int>> arr;
// 좌하단 대각선에 sum을 저장하기 위해 더 넉넉하게
int max_sum = 0;

int main(int argc, char** argv)
{
	int test_case, T;

	for(test_case = 1; test_case <= 10; ++test_case)
	{
		cin>>T;
		// 초기화
		max_sum = 0;
		arr.assign(100, vector<int>());
		/*for (int i = 0; i<=101; i++) {
			for (int j = 0; j<=101; j++) {
				arr[i][j] = 0;
			}
		}*/

		for (int i = 0; i<100; i++) { // 입력 + 정보 저장
			int row_sum = 0;
			for (int j = 0; j<100; j++) {
				int a;
				// cin>>arr[i][j];
				cin >> a;
				arr[i].push_back(a);

				// arr[i][101] += arr[i][j]; // 행 Sum 저장
				row_sum += a;
			}
			// max_sum = max(max_sum, arr[i][101]);
			max_sum = max(max_sum, row_sum);
		}

		// 1.1, 2.1, 3.1 ....
		for (int i = 0; i<100; i++) { // 열 Sum 저장 + 비교
			int col_sum = 0;
			for (int j = 0; j<100; j++) {
				col_sum += arr[j][i];
			}
			max_sum = max(max_sum, col_sum);
		}

		// 대각선 처리
		// 1.1 , 2.2 , 3,3 ....
		int sum3 = 0;
		for (int i = 0; i<100; i++) {
			sum3 += arr[i][i];
		}
		max_sum = max(max_sum, sum3);

		// 대각선 처리
		// 1.100, 2.99...
		int sum4 = 0;
		for (int i = 0; i<100; i++) {
			sum4 += arr[i][99-i];
		}
		max_sum = max(max_sum, sum4);
		// cout << "max_sum = " << max_sum << " sum4 = " << sum4 << endl;

		cout << "#" <<test_case  << " " << max_sum << endl;
	}

	/*
	 * 제출이력
	 * 14분: 10/0개. -> 출력형식 오류 확인
	 * 16분: 10/1개
	 * 22분 각 변수 초기화 -> 10/1개 -> 똑같은 값을 넣었는데, #1 1712, #2 1741이 나온다. 어디 초기화 안된다
	 * - 각 변수 초기화 확인 및 대각선 처리 확인.
	 * 34분: 배열 위험한 거 같아서 벡터 전환 -> 22분 변동과 같은 사항.
	 */
	return 0;//정상종료시 반드시 0을 리턴해야합니다.
}
```

# SWEA 1954, 달팽이 숫자 (성공)

# 문제 소개

문제 사이트 하이퍼링크

달팽이는 1부터 N*N까지의 숫자가 시계방향으로 이루어져 있다.

다음과 같이 정수 N을 입력 받아 N크기의 달팽이를 출력하시오.

**[예제]**

N이 3일 경우,

| 1 | 2 | 3 |
| --- | --- | --- |
| 8 | 9 | 4 |
| 7 | 6 | 5 |

N이 4일 경우,

| 1 | 2 | 3 | 4 |
| --- | --- | --- | --- |
| 12 | 13 | 14 | 5 |
| 11 | 16 | 15 | 6 |
| 10 | 9 | 8 | 7 |

**[제약사항]**

달팽이의 크기 N은 1 이상 10 이하의 정수이다. (1 ≤ N ≤ 10)

**[입력]**

가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.

각 테스트 케이스에는 N이 주어진다.

**[출력]**

각 줄은 '#t'로 시작하고, 다음 줄부터 빈칸을 사이에 두고 달팽이 숫자를 출력한다.

(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

# 풀이 과정

- 빙글빙글 도는 걸 어떻게 표현할지 고민하다가, 우하좌상 순서로 움직이되 배열 끝에 닿거나 이미 값이 있으면 방향을 바꾸기로 했다.
- 17분쯤 "이미 값이 있는 경우" 조건이 안 걸렸는데, 배열을 초기화하지 않아서 쓰레기 값 때문이었다.
- 32분에 제출했는데 띄어쓰기를 하나 더 출력해서 2/10이 나왔고, 고쳐서 성공했다.

```cpp
#include<iostream>
#include <bits/stdc++.h>

using namespace std;

/*
 * 달팽이 게임.
 * 달팽이는 1부터 N*N까지의 숫자가 시계방향으로 이루어져 있다.
 * 다음과 같이 정수 N을 입력 받아 N크기의 달팽이를 출력
 *
 * 이 빙글뱅글 도는 걸 어떻게 표현할까...
 * - 시작점을 기준으로 우하좌상(달팽이) 처럼 움직이되, 배열의 끝에 닿았거나, 이미 값이 있는 경우 방향 전환?
 */
int main(int argc, char** argv)
{
	int test_case;
	int T;

	cin>>T;
	/*
	   여러 개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
	*/
	for(test_case = 1; test_case <= T; ++test_case) {
		int snail;
		cin>>snail;

		// 우 하 좌 상, 달팽이
		int dx [4] = {0, 1, 0, -1}, dy[4] = {1, 0, -1, 0};

		int arr[101][101] = {0, }; // N이 최대 10
		int x = 0, y = 0;
		int i = 0, num = 1;
		while (true) { // 움직일 수 있는 동안

			// cout << x << " " << y << " -> "<< num << endl;

			// 칸 세기기
			arr[x][y] = num;
			if (num == snail*snail) {
				// cout << x << " " << y << " -> "<< num << endl;
				break;
			}
			num++;

			// 아닌 경우 움직이기.

			// 해당 방향으로 움직일 수 없으면 방향 전환
			int nx = x + dx[i], ny = y + dy[i];
			// cout << x << " " << y << " -> "<< arr[x][y] << ",   " << nx << " " << ny <<   " -> "<< arr[nx][ny] << endl;
			if (nx < 0 || ny < 0 || nx >= snail || ny >= snail) { // 배열 밖으로 벗어난다면
				// cout << x << " " << y << " -> "<< arr[x][y] << ",   " << nx << " " << ny <<   " -> "<< arr[nx][ny] << endl;
				// cout << " 방향전환1! " << i << " -> " << (i+1)%4 << '\n';
				i = (i+1)%4;
				x = x+dx[i], y=y+dy[i];

				continue;
			}
			if (arr[nx][ny] != 0) { // 이 조건이 걸리지 않는다.
				// cout << x << " " << y << " -> "<< arr[x][y] << ",   " << nx << " " << ny <<   " -> "<< arr[nx][ny] << endl;
				// cout << " 방향전환2! " << i << " -> " << (i+1)%4 << '\n';
				i = (i+1)%4;
				x = x+dx[i], y=y+dy[i];
				continue;
			}

			x = nx, y = ny;

			// 아니면 현 방향으로 x, y만 갱신
		}

		cout << "#" << test_case << '\n';
		for (int s = 0; s<snail; s++) {
			for (int j = 0; j<snail; j++) {
				cout << arr[s][j] << " ";
			}cout << '\n';
		}

	}

	/**
	 * 17분 이미 값이 있는 때에 조건이 틀림
	 * - 또한 디버깅이 오래 걸렷던 이유는 배열 미초기화로 인한 쓰레기 값으로 인한 조건 통과 오류
	 * - 그래서 두 번째 조건인 값이 비어있지 않은 경우로 판단. 
	 * 32분 제출 2/10 -> ? 띄어쓰기 하나 더 출력해서 오류였었음
	 * 
	 */

	return 0;//정상종료시 반드시 0을 리턴해야합니다.
}
```

# 결과 & 근거

**성공 (32분)**

- 우 → 하 → 좌 → 상으로 직진하다가, 앞이 배열 밖이거나 이미 채워진 칸이면 시계방향으로 방향을 바꾼다.
- 두 방향 전환 블록의 내용이 같아서 `||`로 하나로 합칠 수 있다. 배열은 테스트 케이스마다 0으로 초기화해야 한다.

세 개의 실수 x,y,z가 **등차수열을 이룬다**는 것은, y - x = z - y라는 것과 동치이다.

세 정수 a,b,c가 주어진다. 당신은 음이 아닌 실수 x을 정한 뒤, 세 정수 중 하나에서 x만큼을 더하거나 뺄 수 있다. 당신은 이러한 작업을 <u>정확히 한 번</u> 하여 a,b,c가 등차수열을 이루도록 하려고 한다. 이것이 가능하도록 하는 가장 <u>작은</u> x의 값이 얼마인지 구하는 프로그램을 작성하라.

**[입력]**

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.

각 테스트 케이스는 하나의 줄로 이루어진다. 각 줄에는 세 개의 정수 a,b,c (0≤a,b,c≤1000)가 공백 하나를 사이로 두고 주어진다.

**[출력]**

각 테스트 케이스마다 한 줄에 하나씩, a,b,c가 등차수열을 이루도록 할 수 있는 가장 작은 x의 값을 출력한다. 참값과의 절대 오차 또는 상대 오차가 10-9이하이면 정답 처리된다.x의 값이 정수가 아닐 수 있음에 유의하라. (x값은 소수점 1자리까지 출력한다.)

```cpp
3
0 1 2
0 2 1
4 4 8

출력
#1 0
#2 1.5
#3 2.0
```

# 결과 & 근거

**실패 (35분, TC 18/61)**

- b가 될 값은 a와 c의 평균 (a + c) / 2인데 (c - a) / 2를 썼다. 예제 3개 중 2개가 a = 0이라 차이가 드러나지 않았다.
- 바꿀 수 있는 수는 셋 중 하나뿐이라 후보가 3개다. a, b, c를 각각 바꾸는 경우의 x를 모두 계산해 최솟값을 고르면 된다.
- 세 후보는 |a + c - 2b|의 1/2배, 1배, 1배라서 결국 가운데 b를 바꾸는 경우가 항상 최소다.

```cpp
#include<iostream>
#include <cmath>       // double용 abs (iostream만으로는 컴파일러에 따라 int abs로 잘릴 수 있다)
#include <algorithm>

using namespace std;

int main(int argc, char** argv)
{
	int test_case;
	int T;
	cin >> T;

	cout << fixed;
	cout.precision(1);

	for (test_case = 1; test_case <= T; ++test_case)
	{
		int a, b, c;
		cin >> a >> b >> c;

		// 바꿀 수 있는 수는 a, b, c 중 하나 → 후보는 딱 3개라 전부 계산하고 최솟값을 고른다
		// 등차수열 조건: b - a == c - b  ⇔  a + c == 2b

		// (1) b를 바꾼다: b가 a와 c의 "평균"이 되어야 한다 → b' = (a + c) / 2
		double changeB = abs((a + c) / 2.0 - b);

		// (2) a를 바꾼다: a' = 2b - c
		double changeA = abs(a - (2.0 * b - c));

		// (3) c를 바꾼다: c' = 2b - a
		double changeC = abs(c - (2.0 * b - a));

		// 세 후보 모두 |a + c - 2b|에 비례하는데, b를 바꾸는 쪽만 절반이라 항상 (1)이 최소
		// (다만 시험장에서는 이걸 증명하기보다 후보 3개를 다 계산하는 게 안전하다)
		double x = min(changeB, min(changeA, changeC));

		cout << "#" << test_case << " " << x << '\n';
	}
	return 0;//정상종료시 반드시 0을 리턴해야합니다.
}
```

# 결과 & 근거

**성공 (15분)**

- 자릿수가 적을수록 작은 수라서, 닫힌 공간 2개인 8로 채워 자릿수를 ⌈X/2⌉로 만든다.
- 홀수면 맨 앞에 4를 둔다 (0은 맨 앞에 올 수 없음). X = 1만 답이 0이다.

```cpp
#include <iostream>
#include <string>

using namespace std;

int main(int argc, char** argv)
{
	int test_case;
	int T;
	cin >> T;

	for (test_case = 1; test_case <= T; ++test_case) {
		int x;
		cin >> x;

		// 닫힌 공간: 8 = 2개 (최대), 0·4·6·9 = 1개
		// 자릿수가 적을수록 작은 수 → 8로 최대한 채워 자릿수를 ceil(x/2)로 만든다.
		// 홀수면 1개짜리 하나가 필요한데, 맨 앞에 둘 수 있는 가장 작은 것은 4 (0은 맨 앞 불가)
		if (x == 1) {
			cout << 0 << '\n';   // 0 자체가 정답 (한 자리 0은 허용)
			continue;
		}

		string s = "";
		for (int i = 0; i < x % 2; i++) s += '4';   // 홀수면 맨 앞에 4
		for (int i = 0; i < x / 2; i++) s += '8';   // 나머지는 전부 8
		cout << s << '\n';   // 최대 1,250자리 → 정수형 불가, 문자열로 출력
	}
	return 0;//정상종료시 반드시 0을 리턴해야합니다.
}

```

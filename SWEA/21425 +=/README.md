# SWEA 21425, += (성공)

# 문제 소개

문제 사이트 하이퍼링크

C, C++, Python, Java 등의 언어에는 += 연산자가 있다. 정수형 변수 x, y가 있을 때 “x += y”를 하면 x에 저장된 값이 (기존에 x에 저장되어 있던 값) + (기존에 y에 저장되어 있던 값)으로 바뀐다.

현재 x에 저장된 값은 A, y에 저장된 값은 B이다. 당신은 “x += y” 또는 “y += x” 연산을 원하는 순서대로 원하는 만큼 수행하여, x나 y 둘 중 하나 이상에 저장된 값이 N **초과**가 되게 하려고 한다. 연산을 합쳐서 최소 몇 번 수행해야 하는지 계산하는 프로그램을 작성하라.

**입력**

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.

각 테스트 케이스는 한 개의 줄로 이루어진다. 각 줄에는 세 개의 정수 A, B, N (1 ≤ A, B ≤ N ≤ 10^9)

이 공백 하나씩을 사이로 두고 주어진다.

테스트 케이스의 개수는 600,000개 이상으로 상당히 많음에 유의하라.

**출력**

각 테스트 케이스마다, 한 줄에 하나씩 x나 y 둘 중 하나 이상에 저장된 값이 N **초과**가 되게 하기 위해 “x += y”, “y += x” 연산을 최소 몇 번 수행해야 하는지 출력한다.

# 풀이 과정

- N을 넘으려면 A나 B를 최대한 빨리 키워야 한다는 게 공통 목적이었다.
- DP도 생각했지만 += 연산만으로 시간 안에 충분히 가능하다고 판단했다.
- `10 7 1293`을 A부터 키울 때와 B부터 키울 때로 손으로 비교해보니, 큰 수를 피연산자로 쓰는 쪽이 더 빨리 커졌다.

```cpp
#include<iostream>

using namespace std;

int main(int argc, char** argv)
{
	// 테스트 케이스가 60만 개 이상 → C 표준 입출력과의 동기화를 끊어 cin/cout을 빠르게.
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int test_case;
	int T;

	cin>>T;
	for(test_case = 1; test_case <= T; ++test_case)
	{
		int a, b, n;
		cin >> a >> b >> n;
		int cnt = 0;

		// 매번 "작은 쪽에 큰 쪽을 더한다" → 두 수가 피보나치처럼 가장 빠르게 커진다.
		// 시작할 때 a, b ≤ n 이므로 최소 1번은 연산해야 한다 → 먼저 연산하고 검사.
		while (true) {
			if (a >= b) b += a;
			else a += b;

			cnt++;
			if (a > n || b > n) break;   // 둘 중 하나라도 n "초과"면 끝
		}
		cout << cnt << '\n';
	}
	return 0;//정상종료시 반드시 0을 리턴해야합니다.
}
```

# 결과 & 근거

**성공 (10분 44초)**

- 작은 쪽에 큰 쪽을 더하면 두 수가 피보나치처럼 가장 빠르게 커져서, 최소 횟수가 보장된다.
- 케이스당 최대 약 45번이고, 더하기 직전 값은 ≤ 10⁹이라 합이 int 범위를 넘지 않는다.
- 테스트 케이스가 60만 개 이상이라 입출력 가속을 넣었다.
